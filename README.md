# Türstation für Metzler VDM10

Symcon-Bibliothek mit einem Modul:

- [Türstation für Metzler VDM10](VDM10/README.md): Video-Türstation Metzler VDM10 (2.0) lokal über ISAPI einbinden, ohne Cloud. Klingeln, Türöffner, Zutritte, Personen und Zeitpläne verwalten, mit eigener Kachel als Steuerzentrale.

Dieses Projekt stammt nicht von Metzler oder Hikvision und wird von ihnen weder unterstützt noch geprüft. Metzler, Hikvision und Hik-Connect sind Marken ihrer jeweiligen Inhaber.
